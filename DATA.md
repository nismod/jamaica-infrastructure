# jamaica-infrastructure data description
This file provides a description of the various kinds of input, intermediate and
output data used in this project. Data are located within the `processed_data` (mostly input, some processed output networks) and `results` (intermediate and output analysis results).

Each heading corresponds to a directory in either `processed_data` or `results`.

## processed_data
Input and preprocessed data used by the analysis workflows. Most files are input data, though some final results (like cleaned networks) are also stored here.

### processed_data/adaptation
Adaptation options and costs for infrastructure assets. Contains data on:
- Coastal adaptation foundation data and parameters
- Adaptation options and costs by asset type (from Excel files)
- Self-adaptation strategies for flooding and tropical cyclones

### processed_data/agriculture_data
Agricultural GDP and production data spatially allocated across Jamaica.

### processed_data/boundaries
Administrative and political boundaries of Jamaica used for spatial analysis and clipping datasets.

### processed_data/buildings
Building footprints and attributes including:
- Buildings with assigned economic activity by sector
- Building types and replacement costs
- Damage cost parameters (min, mean, max)

This is one of the largest datasets with ~1M building features.

### processed_data/damage_curves
Damage functions relating hazard intensity to asset damage percentage:
- Asset-to-damage-curve mapping files
- Sector-specific damage curves (transport, water, energy) for different hazard types (TC, flooding, coastal)
- Hazard damage parameters including intensity thresholds and uplift factors

Used by `workflow/1_damage/damage_calculations.py` to calculate direct damages.

### processed_data/flow_mapping
Contains network flow path data created by the transport model. Populated by workflow rules, not raw input data.

### processed_data/hazards
Natural hazard data layers including:
- **Coastal_flood_data/** - Coastal flooding scenarios by RCP and return period
- **Global Flood Map/** - Fluvial and surface flooding data
- **TC_data_fixed_return/** - Tropical cyclone wind speed data by return period
- **hazard_layers.csv** - Metadata describing all hazard layers (path, type, RCP, epoch, return period)

Hazards include flooding (coastal, fluvial, surface) and tropical cyclones (TC).

### processed_data/hotspots
Grid-based analysis infrastructure:
- **grid.tiff** - Raster grid for spatial aggregation of hotspots analysis (generated by workflow)

### processed_data/land_type_and_use
Land cover and land use classifications.

### processed_data/locations
Geographic locations of interest (cities, facilities, etc.).

### processed_data/macroeconomic_data
Economic data including:
- GDP growth rates (used for loss projections)
- Import/export data by industry/sector
- Exchange rates (USD to JMD)

### processed_data/mining_data
Mining sector GDP data spatially allocated.

### processed_data/nbs
Nature-based solutions data.

### processed_data/nbs-river-catchment
River catchment data for nature-based solutions analysis.

### processed_data/networks
Infrastructure network datasets organized by sector:

#### processed_data/networks/transport
- **roads.gpkg** - Road network with nodes and edges layers, preprocessed from OpenStreetMap via open-gira
  - Includes bridge nodes, speed limits, road classifications, damage costs
- **rail.gpkg** - Railway network (nodes and edges)
- **airport_polygon.gpkg** - Airport terminal areas
- **port_polygon.gpkg** - Port facility areas
- **multi_modal_network.gpkg** - Combined multi-modal transport network (generated by workflow)

#### processed_data/networks/water
- **irrigation_assets_NIC.gpkg** - Irrigation infrastructure (nodes and edges)
- **potable_facilities_NWC.gpkg** - Potable water facilities
- **waste_water_facilities_NWC.gpkg** - Wastewater treatment facilities
- **pipelines_NWC.gpkg** - Water pipeline network

#### processed_data/networks/energy
- **electricity_network_v3.1.gpkg** - Electricity transmission and distribution network (nodes and edges)
  - Includes substations, transmission lines, distribution lines

#### processed_data/networks/coastal_infrastructure
- **Jamaica_coastal_protection_areas.gpkg** - Coastal protection zones (generated by workflow)

### processed_data/networks_economic_activity
Networks tagged with economic activity data for loss calculations.

### processed_data/networks_uids
Networks with unique identifiers assigned for visualization:
- **id_lookups/** - Mapping files between asset IDs and unique visualization IDs
- **network_layers.csv** - Metadata for all network layers with UID references

Generated by `workflow/6_etl/` rules.

### processed_data/plots
Static plot outputs and visualization files.

### processed_data/population
Population data and projections used for labor flow modeling.

### processed_data/sensitivity_parameters.csv
Generated sensitivity analysis parameter sets for uncertainty quantification in damage calculations. Contains cost and damage uncertainty parameters. Generated by the `sensitivity_parameters` checkpoint in `workflow/1_damage/_damage.smk`.

### processed_data/single_point_failure
Pre-computed single-point failure scenarios for buildings and other assets.

### processed_data/STORM_RP_rasters
Additional storm return period raster data.

## results
Intermediate and final results from the analysis workflow.

### results/adaptation_benefits_costs_bcr
Benefit-cost ratio (BCR) analysis results for adaptation options:
- Cost-benefit ratios for flooding, tropical cyclone (TC), and coastal adaptations
- Avoided Expected Annual Damages (EAD) and Expected Annual Economic Losses (EAEL)
- Files organized by hazard type and asset class (e.g., `flooding_roads_edges_adaptation_benefits_costs_bcr.csv`)

Generated by `workflow/5a_self-adaptation/benefit_cost_ratio.py` and `workflow/5b_coastal_adaptation/5_benefit_cost_ratio.py`.

### results/adaptation_costs
Adaptation implementation costs:
- Timeseries and NPV (Net Present Value) of adaptation costs
- Unit costs by adaptation option
- Organized into subdirectories by hazard type: `flooding_costs/`, `TC_costs/`, `coastal_costs/`

Generated by `workflow/5a_self-adaptation/adaptation_options_costs.py`.

### results/coastal_adaptation
Results specific to coastal adaptation scenarios (flood defense thresholds applied).

Contains similar structure to main results but with coastal protection applied:
- `direct_damages_summary/` - Damages with coastal protection
- Other subdirectories matching main results structure

### results/coastal_protection_assets
Coastal protection infrastructure analysis:
- **Jamaica_coastal_protection_areas.gpkg** - Defined coastal protection zones by RCP/RP scenarios
- **combined_coastal_protection_area.gpkg** - Union of all coastal protection areas
- **network_protection_mappings/** - Mapping of network assets to the coastal protection zones that would defend them
- **coastal_protection_assets_breakdown.csv** - Count and value of assets protected by each coastal defense zone
- **coastal_protection_processing_layers.gpkg** - Intermediate processing layers

Generated by `workflow/5b_coastal_adaptation/` rules.

### results/direct_damages
Direct physical damage calculations for each asset class across all hazards:
- Organized by asset class: `{asset_gpkg}_{layer}/`
- Contains damage parquet files by parameter set: `{asset}_direct_damages_parameter_set_{N}.parquet`
- **hazard_damage_parameters.csv** - Hazard intensity thresholds and uplift factors used

Generated by `workflow/1_damage/damage_calculations.py` for each asset layer, hazard, and sensitivity parameter set.

### results/direct_damages_summary
Aggregated damage and loss statistics across sensitivity parameter ensembles:
- **{asset}_losses.parquet** - Economic loss estimates (mean, min, max across parameter sets)
- **{asset}_damages.parquet** - Physical damage estimates
- **{asset}_exposures.parquet** - Asset exposure to hazards
- **{asset}_EAD_EAEL.csv** - Expected Annual Damage and Expected Annual Economic Loss

Generated by `workflow/4a_losses/damage_loss_summarised.py`, aggregating over all sensitivity parameter sets.

### results/direct_damages_summary_uids
Same as `direct_damages_summary/` but with unique IDs assigned to assets for visualization purposes. Files are in parquet format rather than CSV.

Generated by `workflow/6_etl/label_assets.py`.

### results/economic_losses
Economic loss results including:
- **single_failure_scenarios/** - Economic losses from single-point infrastructure failures
  - Road/rail edges, road bridges, rail stations, ports, airports, electricity nodes/edges, irrigation, water facilities
  - Files like `single_point_failure_road_rail_edges_economic_losses.csv`

Generated by `workflow/3_criticality/` rules combining transport, electricity, and water failure analyses.

### results/flood_threshold_X
Scenario results with different flood depth thresholds (1.0m, 1.5m, 2.0m, 2.5m) applied to flooding hazards. These represent different levels of flood protection/adaptation.

Each directory contains the same structure as the main results:
- `direct_damages/` - Damages under this flood threshold scenario
- `loss_damage_npvs/` - NPV calculations
- `loss_damage_timeseries/` - Timeseries projections

Generated by applying flood threshold parameters in damage calculations (see `hazard_damage_parameters` rule).

### results/flow_mapping
Transport flow analysis results:
- **sector_to_ports_flow_paths.pq/.csv** - Trade flow paths from economic sectors to ports
- **sector_imports_exports_to_ports_flows.gpkg** - Spatial representation of trade flows
- **origins_destinations_trade_economic_activity.csv** - Origin-destination trade economic values
- **labour_to_sectors_trips_and_activity.pq** - Labor commute flows and associated economic activity
- **labour_trips_and_activity.gpq** - Spatial labor flow data
- **origins_destinations_labour_economic_activity.csv** - Origin-destination labor economic values

Generated by `workflow/2a_transport/trade_activity_flow_mapping.py` and `labour_to_work_flow_mapping.py`.

### results/grid_failures
Electricity grid failure analysis results.

### results/hazard_asset_intersection
Spatial intersection of hazard layers with infrastructure assets:
- Files like `{asset}_splits__hazard_layers__{layer}.geoparquet`
- Assets split at hazard raster boundaries with sampled hazard intensity values
- Used as input for damage calculations

Generated by `workflow/1_damage/split_networks.py`.

### results/hotspots
Spatial hotspot analysis identifying areas of concentrated infrastructure risk:

#### results/hotspots/splits
Assets split by the hotspots analysis grid (similar to hazard_asset_intersection but using analysis grid).

#### results/hotspots/exposure
Raster maps of total asset value (exposure) per grid cell:
- By asset class: `{asset}__{layer}.tiff`
- By sector: `water.tiff`, `energy.tiff`, `transport.tiff`
- All sectors combined: `all_sectors.tiff`

#### results/hotspots/damages_rp
Direct damages calculated for hotspots analysis.

#### results/hotspots/EAD
Expected Annual Damage raster maps:
- By asset and hazard: `{asset}__{layer}__{hazard}.tiff`
- By sector and hazard: `{sector}__{hazard}.tiff`
- By hazard across all sectors: `all_sectors__{hazard}.tiff`
- Flood aggregations: `{asset}__all_flood.tiff`
- Total EAD: `{asset}__{layer}.tiff` (all hazards)

Hazards include: cyclone, coastal, fluvial, surface, all_flood

Generated by `workflow/4b_hotspots/` rules.

### results/loss_damage_npvs
Net Present Value calculations for damages and economic losses:
- Files like `{asset}_{layer}_EAD_EAEL_npvs.csv`
- NPV of Expected Annual Damages and Expected Annual Economic Losses over projection period
- Used for adaptation benefit-cost analysis

Generated by `workflow/5a_self-adaptation/damage_loss_timeseries_and_npv.py`.

### results/loss_damage_timeseries
Time series projections of damages and economic losses:
- Files like `{asset}_{layer}_EAD_timeseries_{aggregate}.csv`
- Files like `{asset}_{layer}_EAEL_timeseries_{aggregate}.csv`
- Aggregates: `amin` (minimum), `mean`, `amax` (maximum) across uncertainty
- Annual values from baseline year to projection end year

Generated by `workflow/5a_self-adaptation/damage_loss_timeseries_and_npv.py`.

### results/transport_failures
Transport network failure analysis:

#### results/transport_failures/nominal
Baseline flow data without failures:
- **all_flows.pq** - Combined labor and trade flows

#### results/transport_failures/scenario_results
Single-link failure results:
- **single_link_failure_{chunk}.csv** - Results split into chunks for parallel processing
- Economic losses when individual road/rail links are removed

#### results/transport_failures/transport_scenario_edge_map.csv
Mapping of edge IDs to processing chunks.

#### results/transport_failures/single_station_failures_scenarios.csv
Railway station failure scenarios and resulting economic losses.

#### results/transport_failures/single_bridge_failures_scenarios.csv
Road bridge failure scenarios and resulting economic losses.

Generated by `workflow/3_criticality/` rules.
